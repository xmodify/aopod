# คู่มือการติดตั้งและใช้งาน AOPOD Agent (สำหรับโรงพยาบาลและผู้ดูแลระบบ)

โปรแกรม **AOPOD Agent** เป็นโปรแกรมขนาดเล็ก (Single Binary `.exe` พัฒนาด้วยภาษา Go) สำหรับติดตั้งที่เครื่องแม่ข่ายหรือคอมพิวเตอร์ของโรงพยาบาล เพื่อดึงข้อมูลบริการทางการแพทย์ (ผู้ป่วยนอก, ผู้ป่วยใน, สถานะเตียง Real-time) จากฐานข้อมูล HOSxP และส่งเข้าสู่ระบบกลาง AOPOD โดยอัตโนมัติ

---

## 🌟 จุดเด่นของโปรแกรม
1. **ไม่ต้องติดตั้งโปรแกรมเสริม**: เป็นไฟล์ `.exe` ตัวเดียว ไม่ต้องลง PHP, Python หรือ Node.js เพิ่มเติม
2. **มีหน้าจอ Web GUI สวยหรูในตัว**: ดับเบิ้ลคลิกเปิดโปรแกรม จะเปิดหน้าต่าง Dashboard บน Browser (`http://localhost:8989`) ให้ตั้งค่าและดูสถานะได้ทันที
3. **ติดตั้งเป็น Windows Service ได้ใน 1 คลิก**: ทำงานในพื้นหลังตลอด 24 ชั่วโมง บูตเครื่องใหม่ก็ทำงานต่ออัตโนมัติ
4. **รองรับการสั่งการจากส่วนกลาง**: แอดมินกลางสามารถกดสั่ง Sync ข้อมูลย้อนหลัง หรือปรับรอบเวลาส่งได้โดยตรงจากหน้าเว็บ AOPOD

---

## 🛠️ ขั้นตอนการติดตั้งสำหรับ IT โรงพยาบาล (ง่ายๆ 3 ขั้นตอน)

### ขั้นตอนที่ 1: ดาวน์โหลดโปรแกรมและดู Token
1. เข้าสู่ระบบ AOPOD ของผู้ดูแลระบบที่เมนู **"จัดการ Agent รพ." (`/manage/agents`)**
2. กดปุ่ม **"ดาวน์โหลด AOPOD-Agent.exe"**
3. ที่แถวของโรงพยาบาลท่าน กดปุ่ม **"ดู Token"** เพื่อคัดลอก Token ประจำโรงพยาบาล (หรือกดปุ่ม "Config" เพื่อโหลดไฟล์ตั้งค่าสำเร็จรูป)

---

### ขั้นตอนที่ 2: เปิดโปรแกรมและตั้งค่าผ่าน Web GUI
1. ดับเบิ้ลคลิกเปิดไฟล์ **`AOPOD-Agent.exe`** ได้จากทุกที่ (เช่น Desktop หรือโฟลเดอร์ใดก็ได้)
2. โปรแกรมจะรันในพื้นหลังที่ **System Tray (มุมขวาล่าง)** และเปิดหน้าต่าง Web GUI บน Browser ที่ **`http://localhost:8989`** ให้อัตโนมัติ
3. ไปที่แท็บ **"ตั้งค่าการเชื่อมต่อ" (Settings)**:
   - กรอก **รหัสสถานพยาบาล (Hospcode)**, **ชื่อ รพ.** และวาง **API Token**
   - กรอก **Host IP, Port, Username, Password, Database** ของฐานข้อมูล HOSxP ประจำ รพ.
   - กดปุ่ม **"ทดสอบเชื่อมต่อ HOSxP"** และกดปุ่ม **"ทดสอบ Token / Server"**
   - กดปุ่ม **"บันทึกการตั้งค่า"**
4. *หมายเหตุ: ไฟล์ตั้งค่า `config.yaml` จะถูกบันทึกไว้ใน User Roaming AppData (`%APPDATA%\AOPOD-Agent\config.yaml`) อย่างปลอดภัยโดยอัตโนมัติ*

---

### ขั้นตอนที่ 3: ทดสอบส่งข้อมูลและติดตั้งเป็น Windows Service
1. ในแท็บ **"ภาพรวม & ส่งข้อมูล"**:
   - เลือกช่วงวันที่ที่ต้องการ (เช่น ย้อนหลัง 10 วัน) แล้วกดปุ่ม **"เริ่มส่งข้อมูล (Sync Now)"**
   - ตรวจสอบในกล่องกิจกรรม (Live Log) ว่าส่งข้อมูล OPD, IPD และเตียงสำเร็จ
2. ไปที่แท็บ **"จัดการ Windows Service"**:
   - กดปุ่ม **"ติดตั้งเป็น Windows Service"**
   - กดปุ่ม **"เริ่มทำงาน (Start)"**
3. ปิดหน้าต่าง Browser ได้เลย ตัว Agent จะรันทำงานอัตโนมัติตามรอบเวลาตลอด 24 ชั่วโมงในพื้นหลัง

---

## 💻 คำสั่งจัดการผ่าน Command Line (CLI สำหรับผู้ชำนาญการ)

| คำสั่ง | การทำงาน |
| :--- | :--- |
| `.\AOPOD-Agent.exe` | รันโปรแกรมในโหมด Desktop GUI (เปิดพอร์ต 8989) |
| `.\AOPOD-Agent.exe test-db` | ทดสอบการเชื่อมต่อฐานข้อมูล HOSxP ผ่าน Console |
| `.\AOPOD-Agent.exe test-api` | ทดสอบการเชื่อมต่อและ Token กับ AOPOD Server |
| `.\AOPOD-Agent.exe sync-now` | สั่งส่งข้อมูลย้อนหลังทันที 1 รอบ |
| `.\AOPOD-Agent.exe install` | สั่งติดตั้งเป็น Windows Service ในระบบ |
| `.\AOPOD-Agent.exe start` | สั่ง Start Windows Service |
| `.\AOPOD-Agent.exe stop` | สั่ง Stop Windows Service |
| `.\AOPOD-Agent.exe uninstall` | สั่งถอนการติดตั้ง Windows Service ออกจากเครื่อง |

---

## ☁️ การสั่งงานระยะไกลจากหน้าเว็บส่วนกลาง AOPOD (`/manage/agents`)

ผู้ดูแลระบบกลาง (สสจ. / แอดมิน AOPOD) สามารถสั่งการ Agent ของแต่ละ รพ. ได้โดยตรง:
1. **ดูสถานะ Live Heartbeat**: ตรวจสอบว่า รพ. ไหน Agent กำลังออนไลน์หรือออฟไลน์
2. **สั่งดึงข้อมูลย้อนหลัง (Remote Backfill)**:
   - กดปุ่ม **"สั่ง Sync"** ที่ รพ. ที่ต้องการ หรือกด **"สั่ง Sync ทุก รพ."**
   - ระบุวันที่เริ่มต้น และวันที่สิ้นสุด
   - ระบบจะส่งคำสั่งไปยัง Agent ของ รพ. นั้นๆ เพื่อ Query และส่งข้อมูลกลับมาให้อัตโนมัติ
3. **สร้าง/รีเซ็ต Token**: กดปุ่มรูปกุญแจ เพื่อสร้าง Token ใหม่ให้ รพ. หาก Token เดิมหมดอายุหรือรั่วไหล
